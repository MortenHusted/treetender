# Support

Use [issues](https://github.com/MortenHusted/treetender/issues) for reproducible bugs, questions and proposals. Search existing reports first. Include the TreeTender version or commit, operating system, a small sanitized declaration, the exact command and expected versus actual behavior.

Reproduce resource problems with disposable data. Remove credentials and identifying paths from logs; registry contents and local overlays can contain private information. Do not upload a real database or a complete agent profile.

For vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of opening a public issue. For code changes, read [CONTRIBUTING.md](CONTRIBUTING.md).

TreeTender is experimental. There is no paid support agreement, guaranteed response time or commitment to maintain old development commits. Current provider capabilities and limitations are documented in [usage](docs/usage.md) and [adapters](docs/adapters.md).
